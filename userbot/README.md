# Авторассылка по группам (userbot, п.56)

Постинг **фото + текст** в группы от имени **твоего аккаунта** (не бота) по расписанию.
Управление — из админки бота (**⚙ Админка → 📣 BC**). Движок — отдельный процесс на Telethon (MTProto).

> ⚠️ Это автоматизация пользовательского аккаунта — формально против ToS Telegram.
> Встроены рандом-паузы, обработка FloodWait и суточный лимит. Держи интервал человеческим.
> Файл сессии (`*.session`) = ключи от аккаунта, он в `.gitignore` и в гит не попадает.

---

## Архитектура

| Что | Где | Роль |
|-----|-----|------|
| Админка, раздел 📣 BC | `bot/handlers/admin/broadcast.py` | настройки + список групп → пишет в БД |
| Общий стор | `common/broadcast_store.py` | CRUD по БД, без aiogram/telethon |
| Модели | `common/models/broadcast.py` | `bc_state` (конфиг), `bc_target` (группы) |
| Постер | `userbot/main.py` | читает БД каждые 15с, шлёт в активные группы |
| Разовый вход | `userbot/login.py` | создаёт файл сессии |
| Список групп | `userbot/list_dialogs.py` | печатает id/@username групп |

Бот и постер общаются **через БД** (флаги `enabled` / `run_now` / `interval`), без IPC.

## Запуск (по шагам)

### 1. API-ключи — один раз
Нужны, иначе ничего не стартует (сейчас в `.env` пустые).
1. https://my.telegram.org → вход по своему номеру.
2. **API development tools** → создать приложение (App title любой, platform — Desktop).
3. Скопировать `api_id` (число) и `api_hash` (строка).
4. Вписать в `.env`:
   ```
   TG_API_ID=12345678
   TG_API_HASH=abcdef0123456789abcdef0123456789
   USERBOT_PHONE=+48600000000
   ```

### 2. Вход в аккаунт — один раз
```bash
.venv/bin/python -m userbot.login
```
Ввести номер → код из Telegram → 2FA-пароль, если стоит. Создаётся файл сессии.

### 3. Узнать id групп
```bash
.venv/bin/python -m userbot.list_dialogs
```
Выводит таблицу `тип | id | username | название`.
- **публичная** группа → можно `@username` или id;
- **приватная** (username = `-`) → только числовой **id** (с минусом, `-100…`), целиком.

### 4. Запустить постер
```bash
.venv/bin/python -m userbot.main
```
Крутится в фоне, шлёт по заданному интервалу. Остановить — Ctrl+C.

## Настройка в боте (📣 BC)

- **Группы** — добавить (по одной на строку: `@username` или `-100…`), вкл/выкл/удалить.
- **Текст** — подпись к фото (caption).
- **Фото** — прислать картинку, сохранится в `userbot/media/`.
- **Интервал** — минут между циклами рассылки.
- **Паузы** — случайная задержка между группами (антифлуд), мин/макс секунд.
- **Лимит/сутки** — максимум отправок за день (дефолт 200), сбрасывается в полночь.
- **🟢 Включить / 🔴 Выключить** — главный тумблер.
- **▶️ Отправить сейчас** — разовый прогон для проверки.

Статус (последний прогон, счётчик за сутки, ошибки по группам) виден на экране раздела.

## Антифлуд и безопасность

- Случайная пауза между группами (`delay_min`..`delay_max`).
- Обработка `FloodWaitError` — ждём столько, сколько требует Telegram.
- Суточный лимит `daily_cap`.
- Ошибка по конкретной группе пишется в `bc_target.last_error`, остальные идут дальше.
- Код/2FA вводит только владелец аккаунта; я (Claude) их не касаюсь.
- Сессия и медиа — в `.gitignore`.

## Диагностика

| Симптом | Причина / что делать |
|---------|----------------------|
| `❌ Нет сессии` при `list_dialogs`/`main` | не выполнен Шаг 2 — сделать `userbot.login` |
| падение на старте с `TG_API_ID` | пустой/битый `api_id` в `.env` — Шаг 1 |
| группа не получает пост | проверь, что состоишь в ней и постинг разрешён; смотри `last_error` в 📣 BC |
| `FloodWait` надолго | слишком частый интервал — увеличь интервал и паузы |
